# Brand + Google Drive workflow

## Standing brand routing

- OzArmour: http://ozarmour.co/
- BeeKeepingGear: https://www.beekeepinggear.com.au/
- Default campaign output: one finished video per brand.
- Never mix footage, logos, claims, offers, or endcards between brands.

## Intake

1. Authenticate/check Google Workspace access.
2. List the supplied Drive folder and identify video, logo, copy, and reference assets.
3. Download a working copy; leave source files untouched.
4. Create or use `<working-folder>/edit/` for all generated files.
5. Inspect actual frames, not only metadata, before selecting shots.

## Claims and site references

Use each brand's official site to verify current product details and offers before writing factual on-screen copy. If a site cannot be checked, restrict copy to user-supplied or visibly supported claims and flag uncertain claims.

## Transcription constraint

ElevenLabs is deferred. Do not block inventory, visual review, overlays, or rendering on ElevenLabs. If accurate word-level subtitles cannot be produced with an available path, report the limitation instead of fabricating captions.

## Delivery

Self-evaluate every rendered video before delivery. Return the local paths and, when a destination Drive folder was supplied, upload there only after the destination and files are clear. Scheduled jobs must contain enough context to run without asking questions; normal chat requests can use the same workflow interactively.
